# Getting started

Install the
[Wakiita](https://github.com/larok00/wakiita)
plugin for your agent of choice.
It includes Ryōribon, Shokunin, and change-capture.

## Ryōribon

Ryōribon means cookbook.
Tsukurikata translates to "way of making".

Type `/`, select Wakiita's **Ryōribon** skill,
and tell your agent the following:

```text
Learn my tsukurikata.
```

If the skill doesn’t appear in the `/` menu,
ask it to use Wakiita's Ryōribon skill by name.

Your agent will help you choose a name
and location for your `oma-<name>` repository,
then start with one component of your setup.
Machine-specific preferences can belong to a named profile.

### Ippin

Your Oma-repository holds the recipes.
Each **ippin**, or dish,
describes how to install
and configure one part of your setup:
Chrome, Tailscale, or your desktop, for example.
