# Tracking changes

Whenever you want a check-up, type `/`,
select Wakiita's **change-capture** skill,
and tell your agent the following:

```text
Review my configuration changes and update my Oma-repository.
```

Give your agent the repository path
and the component you want checked.
It will update existing recipes,
using Ryōribon for components
that do not yet have an ippin.
