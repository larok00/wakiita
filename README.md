## Contributing

Wakiita is designed to create personalized Oma-repositories
from Omarchy setups and orchestrate their installation.

Wakiita owns reusable workflows and the [ippin format](plugins/wakiita/docs/ippin-spec.md);
Oma-repositories own personal preferences and component-specific setup instructions.

Creation initially targets Omarchy; planning must handle mixed-platform manifests.

See [Tests](tests/README.md) for tooling checks and agent rehearsals.
